# Responsive Portfolio Website

A mobile-friendly personal portfolio website with Home, About, Skills, Projects,
and Contact sections — built with HTML5, CSS3, and Bootstrap 5, as part of the
InternSpark Frontend Development internship (Task 1).

## Live Demo
[Add your GitHub Pages link here once deployed]

## Features
- Fixed navbar with smooth scroll to each section
- Active nav-link highlighting as you scroll (vanilla JavaScript)
- Fully responsive layout — desktop, tablet, and mobile
- Animated hero section (fade-up entrance, hover effects on the profile photo)
- Skill cards with icons for HTML5, CSS3, JavaScript, and Python
- Project cards linking out to GitHub repositories
- Contact form with client-side validation and a confirmation message
- Custom color palette and scrollbar, built with CSS variables

## Tech Stack
HTML5, CSS3 (with CSS variables), Bootstrap 5, Bootstrap Icons, vanilla
JavaScript (ES6+)

## How to Run Locally
1. Clone the repo:
   ```bash
   git clone https://github.com/bhagya-2006/portfolio.git
   ```
2. Open `index.html` in your browser — no build step or server needed

## How to Deploy on GitHub Pages
1. Push this folder to a GitHub repository
2. Go to **Settings > Pages**
3. Under "Source", select the `main` branch and `/ (root)` folder → **Save**
4. Your site will be live at `https://<username>.github.io/<repo-name>/`
